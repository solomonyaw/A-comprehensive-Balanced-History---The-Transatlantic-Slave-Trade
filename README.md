## 📖 About This Project

This book is a research-driven exploration of the transatlantic slave trade. It presents a balanced historical analysis based on:

- Public historical archives  
- Academic research literature  
- Abolitionist writings  
- African and European historical records  
- AI-assisted research synthesis  

It aims to provide a comprehensive understanding of slavery without oversimplification or racial generalization.
